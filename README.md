## 🎨 มาตรฐานการออกแบบและการแสดงผล (Executive Presentation Standard)

* **อัตราส่วนสไลด์ 16:9:** ควบคุมขอบเขตและระยะห่างเพื่อให้ฉายขึ้นจอหรือเปิดบนแท็บเล็ตได้สวยงามพอดีจอ ไม่ต้องเลื่อนจอ (No unnecessary scrolling)
* **ชุดสีทางการ (Executive Ocean & Emerald):**
  * Navy Blue (`#002b49`, `#004b87`): แถบหัวเรื่องและตารางหลัก
  * Vibrant Cyan (`#0284c7`): ข้อมูลสนับสนุนและไฮไลต์
  * Amber / Gold (`#d97706`, `#ffcc00`): ผลคะแนน Hero Score และดาวผลงาน
  * Emerald Green (`#16a34a`): ผลสัมฤทธิ์และสถานะความสำเร็จ
* **ระบบ 2 โหมด (Preview vs Edit):**
  * โหมดนำเสนอ: ป้องกันการเผลอแก้ไขโดยไม่ได้ตั้งใจ
  * โหมดแก้ไขข้อความ: มีแถบเครื่องมือ หนา-เอียง-ขีดเส้นใต้ และบันทึกข้อมูลลง LocalStorage แยกรายไตรมาส
* **ปุ่มฟังก์ชันลัด:**
  * `🖼️ ส่งออกภาพ (PNG)` ความละเอียดสูง 2 เท่า
  * `📋 คัดลอกภาพ` ส่งเข้าคลิปบอร์ดสำหรับวางใน PowerPoint ทันที
  * `📄 ส่งออก PDF (เต็มแผ่น)` ขนาด Landscape
  * `🖨️ พิมพ์` พิมพ์ตรงลงกระดาษ A4 แนวนอน
  * `🔲 เต็มจอ` ขยายเต็มหน้าจอคอมพิวเตอร์
